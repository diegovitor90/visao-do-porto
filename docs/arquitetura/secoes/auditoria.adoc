=== Contradições históricas e precedência

A proposta antiga de `Cliente -> Spring -> FastAPI` para transporte da imagem
está superada pela decisão aprovada nesta revisão. O ADR-001 registra Java fora
do caminho principal dos frames. Preservam-se os documentos antigos como histórico;
para a direção arquitetural, usar esta revisão e o ADR.

`Capacitacao` já existe e registra treinamento realizado por trabalhador.
Separar catálogo de cursos e certificações é proposta futura, não pendência
de criação de uma classe inexistente. SQL Server tem driver no pom.xml,
mas a configuração ativa é H2; não há requisito confirmado para SQL Server.
