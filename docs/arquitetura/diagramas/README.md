# Diagramas editáveis

Editar apenas os `.puml` em [fontes](fontes/). O build gera SVG e PNG em
[imagens](imagens/) e incorpora SVG no HTML/PDF. Não editar exportações à mão.

01 contexto atual; 02 containers atuais; 03 containers alvo; 04 domínio;
05 UML Java atual; 06 UML proposto; 07 DER atual; 08 DER futuro;
09 DFD administrativo; 10 DFD visual atual; 11 DFD operacional proposto.

da biblioteca padrão embarcada no PlantUML; não fazem include remoto.
Layout Smetana é usado para dispensar instalação de Graphviz.
