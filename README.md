# Visão do Porto

MVP acadêmico de apoio à segurança portuária: detecção de pessoas, capacete/colete, rastreamento ByteTrack, zonas e regras, alertas revisáveis e consulta de treinamentos vinculada a cadastro de demonstração.

## Situação

Planejamento revisado em 12/11/2026. Código do protótipo ainda precisa ser disponibilizado; as tarefas técnicas estão abertas. Primeiro piloto em laboratório, sem comprovação de desempenho no porto.

O ID de trajetória não comprova identidade. A consulta de treinamento usa vínculo confirmado pelo operador e dados fictícios; ter treinamento não equivale automaticamente a ter permissão de acesso.
